Pluggable Ingestion

Five ingestor types (PCAP offline, live libpcap capture, NetFlow/sFlow/IPFIX, Zeek logs, AWS/GCP/Azure cloud flow logs) all publishing to a unified Kafka topic.

Tiered Detection

Fast path uses Isolation Forest exported to ONNX Runtime for sub-10ms scoring. Deep path runs LSTM Autoencoder (unsupervised) + XGBoost (supervised) + optional Graph Neural Network for topology-aware analysis.

Hybrid ML Strategy

Phase 1: LSTM Autoencoder learns normal traffic patterns with no labels. Phase 2: XGBoost fine-tuned on CICIDS2017 + UNSW-NB15 for multi-class attack classification.

Production DevSecOps

GitHub Actions CI/CD (lint → test → build → deploy), Kustomize K8s manifests, k3d local cluster, GitOps promotion to prod, MLflow model registry, Prometheus + Grafana observability.
